## 二、实验 0 的详细说明

### 目的
验证 bge-m3 的向量空间是否包含语言结构。

### 方法
```
1. 选取 10 对平行句（中 - 英）
2. 用 bge-m3 编码：enc(CN) -> V_cn, enc(EN) -> V_en
3. 计算 cosine_similarity(V_cn, V_en)
4. 判断：相似度 > 0.85 说明 latent 空间已包含跨语言结构
```

### 关键问题
**相似度 < 0.85 怎么办？**
- 说明 bge-m3 的 latent 空间**不包含**足够的跨语言结构
- 需要更深层的网络或不同的编码器

**相似度 > 0.85 怎么办？**
- 说明 latent 空间已经足够丰富
- 可以做实验 1（跨语言映射）
- 后续往"持续演化"方向走
