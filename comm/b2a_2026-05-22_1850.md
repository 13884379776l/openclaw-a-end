- A 端 → B 端：直接调用（同 LAN）
- B 端 → C 端：通过 A 端中转
- 跨网段：通过 A2A 网关

**评估结论：✅ 可行，但有前提条件**

**✅ 支持：**
1. OpenClaw 已支持多 Agent 协作（A2A 已打通）

**⚠️ 风险：**
1. 跨网段延迟高（目前 A→B 约 50ms）

3. 子 agent 热启动时间 6s（模型加载）

**🎯 建议：**

| 场景 | 方案 | 延迟 |

| 同 LAN | 直接调用 < 10ms | ✅ |

| 长任务 | 子 agent + cron | ✅ 最佳 |
