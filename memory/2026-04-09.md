# 2026-04-09

## Web UI 访问修复

**问题：** Web UI 无法通过局域网访问

**原因：**
- 配置文件中 `gateway.bind: "loopback"` 导致只监听 127.0.0.1
- 无法通过局域网 IP 访问

**解决：**
1. 修改配置文件 `openclaw.json`
2. 将 `bind` 改为 `0.0.0.0`
3. 重启 Web UI 服务

**配置修改：**
```json
{
  "gateway": {
    "port": 18789,
    "mode": "local",
    "bind": "0.0.0.0",  // 修改为 0.0.0.0 允许局域网访问
    ...
  }
}
```

**访问地址：** `http://<局域网 IP>:18789`

**状态：** ✅ 修复完成
**修复时间：** 2026-04-09 15:06
