## 根因分析

### 为什么 `agent_id` 始终是 `"default"`？

1. **`pickAgentId` 在 `executor.js` 中**，被 Node ESM 模块缓存
2. **`index.js` 的 config fallback 改了**，但 `this.defaultAgentId` 在构造时传入
3. **B 端发来的消息没带 `message.agentId`**，导致 `pickAgentId` 走 fallback 分支
4. **`plugins enable` 的 hot-reload 不会刷新 ESM 模块缓存**
5. **需要 clean Gateway 重启**让 Node 重新 require executor.js

### 为什么 A2A 18800 反复掉线？

1. **EADDRINUSE** — 之前有僵尸 Node 进程占用了 18800
2. **`plugins enable` CLI 进程被 SIGKILL** — 导致插件实例被清理
3. **频繁重启** — 我自己触发了 ~7 次 Gateway 重启
