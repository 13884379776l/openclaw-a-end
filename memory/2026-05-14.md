## 识别图像功能讨论 (00:33)
- 用户反馈当前"非文本模型无法识别图"的问题
- 实际原因是模型注意力在图片时只能看到小方块颜色+模糊状态（非真正观察）
- 核心点：媒体理解能力尚待提升 / 用户可能没图
- OpenClaw 服务端会先直接喂图片给模型，但 media understanding 能力有限
- 训练数据集的缺失不代表缺陷缺失，需要"更高的训练"或"更细的注视"
