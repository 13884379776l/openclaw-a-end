### 1. 交互式运行中临时设置
如果你正在使用 `ollama run <model_name>`，可以在对话框中输入以下命令来更改当前会话的上下文窗口：

```bash
/set parameter num_ctx 4096
```
*(将 `4096` 替换为你想要的任何数值，例如 `8192` 或 `32768`)*

### 2. 通过 API 调用设置
如果你通过 API（如 curl、Python 代码等）调用 Ollama，可以在请求的 `options` 字段中指定 `num_ctx`：

**Curl 示例：**
```bash
curl http://localhost:11434/api/generate -d '{
  "model": "llama3.2",
  "prompt": "Why is the sky blue?",
  "options": {
    "num_ctx": 8192
  }
}'
```

**Python (OpenAI 兼容客户端) 示例：**
```python
client.chat.completions.create(
    model="llama3.2",
    messages=[{"role": "user", "content": "Hello"}],
    extra_body={"options": {"num_ctx": 8192}}
)
```

### 3. 创建自定义模型（永久设置）
如果你想让某个模型始终使用特定的上下文窗口，可以创建一个自定义的 `Modelfile`。

1. 创建文件 `Modelfile`，内容如下：
   ```dockerfile
   FROM llama3.2
   PARAMETER num_ctx 32768
   ```
2. 构建新模型：
   ```bash
   ollama create my-llama3-longctx -f Modelfile
   ```
3. 运行新模型：
   ```bash
   ollama run my-llama3-longctx
   ```

### 4. 设置全局默认值
你可以通过环境变量 `OLLAMA_CONTEXT_LENGTH` 设置 Ollama 服务器的默认上下文长度。这会影响所有未明确指定 `num_ctx` 的模型。

**Linux/macOS:**
```bash
OLLAMA_CONTEXT_LENGTH=8192 ollama serve
```

**Windows (PowerShell):**
```powershell
$env:OLLAMA_CONTEXT_LENGTH=8192; ollama serve
```

### 如何确认当前设置？
运行以下命令查看模型的详细信息，包括当前使用的参数：
```bash
ollama show <model_name>
```
在输出中查找 `num_ctx` 参数。如果未明确设置，它会显示默认值（通常为 2048 或 4096，具体取决于模型和 Ollama 版本）。

### 注意事项
*   **内存限制**：增大 `num_ctx` 会显著增加 VRAM/RAM 使用量。如果超出硬件限制，模型可能无法加载或运行速度极慢。
*   **模型能力**：并非所有模型都支持超长的上下文。请确保你设置的 `num_ctx` 不超过模型训练时支持的最大上下文长度（例如 Llama 3.1 支持 128K，而旧模型可能仅支持 8K）。
*   **默认值**：Ollama 的默认上下文窗口通常较小（如 2048 或 4096），因此对于长文本任务，手动设置 `num_ctx` 是必要的。
