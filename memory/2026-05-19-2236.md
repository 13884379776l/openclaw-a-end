## 二、核心概念总结

### 1. 错误分类（最重要）

```
瞬时错误（可重试）:
  - 网络超时
  - 文件被占用
  - 服务暂时不可用
  - 资源锁竞争

永久错误（不应重试）:
  - Access Denied（权限不足）
  - 文件不存在
  - 语法错误
  - 参数错误
```

**关键教训：** 不要对所有错误都重试。retry 只对 transient error 有效，对 permanent error 重试只是浪费时间和资源。

### 2. 智能重试模式

```powershell
function Invoke-Retry {
    param(
        [ScriptBlock]$ScriptBlock,
        [int]$MaxRetries = 3,
        [int]$DelaySeconds = 1,
        [Type[]]$RetryableErrors = @([System.Net.WebException], [IO.IOException])
    )
    
    $attempt = 0
    do {
        $attempt++
        try {
            & $ScriptBlock
            return  # 成功，退出
        } catch {
            # 判断是否是可重试的错误
            if ($RetryableErrors -and 
                $_.Exception.GetType() -notin $RetryableErrors) {
                throw  # 不可重试的错误，直接抛出
            }
            
            if ($attempt -lt $MaxRetries) {
                $backoff = [Math]::Pow(2, $attempt - 1) * $DelaySeconds
                Write-Warning "Attempt $attempt failed, retrying in ${backoff}s..."
                Start-Sleep -Seconds $backoff  # 指数退避
            } else {
                throw  # 达到最大重试次数，抛出错误
            }
        }
    } while ($attempt -le $MaxRetries)
}
```

### 3. 脚本健壮性 checklist

- [ ] 使用 `Set-StrictMode -Version Latest`
- [ ] 所有外部命令加 `-ErrorAction Stop`
- [ ] 用 `try/catch/finally` 包裹关键操作
- [ ] 区分 transient 和 permanent 错误
- [ ] 使用指数退避（exponential backoff）
- [ ] 设置最大重试次数，不无限重试
- [ ] 日志记录（至少记录 attempt 和 error）
- [ ] 避免 `SilentContinue` 掩盖错误
- [ ] 使用 `[CmdletBinding()]` 让函数支持 `-Verbose/-Debug`
