# OpenClaw 2026.5.19 新版本特性学习笔记

> 学习时间：2026-05-21 10:55 GMT+8
> 版本：2026.5.19 (a185ca2) → 从 2026.5.18 升级

## 🎯 对我们 A 端最相关的特性

### 1. Cron 重大改进（最值得关注！）

**Cron 任务与主会话解耦**
- 主会话的定时任务现在运行在独立的 cron wake lane 上，不再阻塞人类聊天
- 之前我们遇到的 cron 超时问题（300s）有根本性改善
- 隔离任务的 exec 拒绝现在有结构化元数据，不会误判正常回复为"拒绝"
- 恢复的工具警告保留在成功定时任务中，最终 cron 输出不再被后处理警告覆盖

**→ 这对我们很重要**：之前 LLM 推理的 cron 任务频繁超时的问题，现在有更可靠的底层执行机制。我们的 PowerShell 脚本 cron 任务（L1 流水、weekly-backup）运行会更稳定。

### 2. Ollama 提供商默认工具支持

**未知能力的 Ollama 模型默认启用工具**
- 当 Ollama `/api/show` 未返回能力信息时，模型默认被视为 tool-capable
- 这意味着 bge-m3、bge-m3-unified 等模型可能也能用工具了

**→ 值得测试**：之前嵌入模型不能用的问题可能自动解决了。

### 3. Gateway 启动优化

**启动日志与插件服务并行**
- Gateway 启动时，日志和插件服务启动与 channel sidecars 重叠，减少重启就绪延迟
- 更新检查启动延迟到 readiness 之后，不再阻塞侧车启动
- **对我们影响**：`openclaw gateway restart` 的速度会更快

### 4. 内存搜索改进

**embedding 上下文释放**
- active-memory 搜索超时时，会关闭本地 embedding 提供者
-  pending 的本地模型加载和 embedding 上下文会被中止和释放
- **→ 之前搜索卡住可能导致资源泄漏，现在已修复**

### 5. Memory 搜索性能修复

**大表扫描不再阻塞事件循环**
- JS 侧 fallback vector 路径使用有界 rowid 批次扫描
- 批次之间 yield 事件循环，不再让 Node.js 主线程被锁定数秒
- **→ MEMORY.md 搜索在数据量大时不再卡死**

### 6. 工具描述缩短

**内置工具描述和 schema 提示全面缩短**
- 覆盖 media, messaging, sessions, cron, Gateway, web, image/PDF, TTS, nodes, plan 等
- 保留路由护栏，但减少 context 中的 token 消耗
- **→ 上下文更紧凑，有效 token 更多**

### 7. 代理配置改进

**exec 批准认证转发**
- agent 批准的异步命令现在能正确转发认证凭据
- 之前批准后的命令可能因认证问题卡住，现在已修复
- **→ 我们之前遇到的 exec 批准问题应该不会再出现**

### 8. 压缩钩子超时

**plugin hook 默认 30 秒超时**
- `before_compaction` 和 `after_compaction` 钩子现在有默认 30 秒超时
- 挂起的插件处理器不再阻塞压缩完成
- **→ compaction 不再因为插件问题无限等待**

### 9. Node 配对改进

**节点授权 scope 修复**
- `openclaw nodes approve` 现在会请求待处理的 node surface approval scopes
- exec-capable 节点授权可以使用 admin-scoped Gateway 凭据
- **→ 我们 A↔B 配对时遇到的 token/permission 问题可能不会再出现**

## 🆕 新增功能（次要，非我们当前环境）

### 技能系统
- 新增 meme-maker skill（模板搜索、SVG/PNG 渲染）
- 新增 node inspector 调试 skill
- 新增 fused diagram generation skill
- 新增 throwaway spike workflow skill
- 新增 Python 调试 skill（pdb, breakpoint, post-mortem, debugpy）
- Obsidian skill 改为使用官方 `obsidian` CLI
- Skills CLI 支持 `--global` 安装共享技能

### Docker/Podman
- `OPENCLAW_IMAGE_APT_PACKAGES` — 运行时中立的 apt 包安装
- `OPENCLAW_IMAGE_PIP_PACKAGES` — 可选 Python 包安装

### 浏览器功能
- 模态对话框管理（等待/处理中/已处理）
- `openclaw browser evaluate --timeout-ms` 扩展长运行页面函数的超时预算

### 代理插件系统
- `defineToolPlugin` + `openclaw plugins build/validate/init` — 创建类型化工具插件
- `/codex plugins list/enable/disable` — 从聊天管理 Codex 插件

### Proxy
- HTTPS 托管正向代理端点支持
- `proxy.tls.caFile` CA 信任作用域

### Mac App
- Settings 页面重新设计（卡片布局、缓存导航）
- Voice & Talk 识别语言和唤醒短语设置优化
- 优先使用 Tailscale/LAN 端点而非 SSH 隧道

### Android
- Talk Mode 切换到实时 Gateway 中继语音会话

### Telegram
- DM 草稿预览（工具进度）
- forum topics 不再阻塞兄弟主题流量
- `/btw` 和只读状态命令不再中止活跃运行

### Discord
- 流式回复预览保留
- 实时语音会话改进（OpenAI realtime）
- thread-bound subagent 初始回复正确路由到 Discord 线程
