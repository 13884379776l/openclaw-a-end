## 🆕 v2026.5.20 新增功能（8 个 Changes）

### 1. Exec Approvals 安全加固 🔒
> 移除旧的 `cat SKILL.md && printf ... && <skill-wrapper>` 白名单兼容路径
- **影响：** skill 文件必须通过 `read` 工具加载
- **意义：** 收紧执行权限，防止技能文件被滥用执行
- **对我们的影响：** 无影响（我们一直用 read 工具加载）

### 2. Discord Voice 大幅改进 🎙️
> Voice sessions 跟随用户进入语音频道，支持多用户交接、DAVE 恢复
- **影响：** Discord 语音会话更稳定
- **对我们的影响：** 无（当前未使用 Discord）

### 3. Discord Voice Profile Context 默认加载 📋
> 实时语音会话默认包含 IDENTITY.md / USER.md / SOUL.md
- **可禁用：** `voice.realtime.bootstrapContextFiles: []`
- **对我们的影响：** 无（当前未使用 Discord）

### 4. Codex Harness 升级 📦
> 升级到 `@openai/codex 0.132.0`，刷新 catalog
- **影响：** 内置 Codex 插件功能更新
- **对我们的影响：** 无（当前未使用 Codex）

### 5. **🆕 Policy 插件（重要新增）** 🛡️
> 新增 bundled Policy 插件，支持：
> - Policy-backed channel conformance checks
> - Doctor lint findings
> - Opt-in workspace repair
- **影响：** **全新的合规检查机制**
- **对我们的影响：** ⚠️ **值得关注** — 未来可能出现 channel conformance 警告

### 6. **🆕 Agent 级 Lean Local Model 模式** ⚡
> `agents.list[].experimental.localModelLean` — 单个 agent 启用 lean 模式
- **影响：** 之前只支持全局启用，现在可以 per-agent
- **对我们的影响：** 如果将来有多个 agent，可以精细控制

### 7. **🆕 xAI Device-Code OAuth** 🔑
> 远程/无头设备可通过 device-code OAuth 登录 xAI
- **影响：** headless 服务器可以使用 xAI 提供商
- **对我们的影响：** 无（当前使用 Ollama）

### 8. **🆕 OpenRouter Provider Routing** 🌐
> 支持 provider-level `params.provider` 路由策略
- **影响：** OpenRouter 多 provider 路由更灵活
- **对我们的影响：** 无（当前使用 Ollama）

## 🔧 关键修复（筛选对我们重要的）

### 直接影响 Ollama/模型
1. **Providers/Ollama:** 未知能力的模型默认 tool-capable
   - `/api/show` 缺失 capabilities 时也能用 tools
   - ✅ **对我们有正面影响**

2. **Agents:** 尊重显式 `models.providers.<id>.timeoutSeconds`
   - 不会在 120s 时强制回退
   - ✅ **稳定了超时行为**

### 直接影响 Cron
3. **Cron:** 主会话计划工作在 cron-owned wake lane 运行
   - 后台 cron 不再阻塞人类主会话聊天
   - ✅ **我们的 cron 任务会更稳定**

4. **Cron:** 保留 legacy 数组格式 `jobs.json`
   - 旧 cron job 升级后不丢失
   - ✅ **避免 cron 任务丢失**

### 直接影响 Memory
5. **Memory/search:** 搜索超时时关闭本地 embedding provider
   - 防止 pending 模型加载泄漏
   - ✅ **解决 memory search 内存泄漏**

6. **Memory-core:** startup 扫描持久化记忆源，增量同步
   - 启动时对比 on-disk transcripts vs index
   - ✅ **memory-core 启动更快**

### 直接影响 Gateway/配置
7. **Doctor:** 警告 `openclaw.json` 明文密钥
   - 包括 model provider API keys
   - ⚠️ **未来 doctor 检查可能报出**

8. **Gateway/secrets:** 拆分轻量 secrets runtime
   - 启动加速（无 SecretRef 时走 fast path）
   - ✅ **Gateway 启动更快**

9. **CLI/update:** 跨版本协议 skew 健康检查
   - 更新后不再静默切换 Node
   - ✅ **避免我们之前遇到过的问题**

### 其他值得关注
10. **Approvals:** `/approve` 通过 trusted approval runtime
    - 不再显示 unknown/expired

11. **Media:** URL path basename 解码
    - `My%20Report.pdf` → `My Report.pdf`
    - 小修

## ⚠️ 需要注意的变化

### 安全相关
- **Doctor 明文密钥警告**：如果 `openclaw.json` 中有明文 API key，doctor 会报警告
- **Exec Approvals 收紧**：技能文件必须通过 read 工具加载，旧白名单方式不可用

### Cron 行为变更
- Cron 主会话工作在独立 wake lane → **不再阻塞主会话**（正面）
- legacy `jobs.json` 格式兼容 → **不会丢失旧任务**

### Memory 改进
- 搜索超时自动关闭 embedding provider → **减少内存泄漏**
- startup 增量同步 → **启动更快**

## 📋 评估：是否值得升级？

### 值得升级的理由 ✅
1. **Ollama tool 支持增强** — 未知能力模型默认支持 tools
2. **Cron 稳定性提升** — 独立 wake lane，不再阻塞主会话
3. **CLI/update 修复** — 跨版本升级不再静默切换 Node（我们之前遇到过）
4. **Memory 泄漏修复** — 搜索超时自动关闭 embedding
5. **Gateway 启动加速** — secrets fast path

### 可以暂缓的理由 ⏸️
1. 8 个新功能中有 4 个与我们无关（Discord/xCodex/xAI）
2. 我们的配置已经稳定，无已知问题
3. 当前 Gateway 运行正常（3m uptime, valid: true）
4. 小版本增量，非重大架构变更

### 建议
**建议升级。** 虽然新功能不多，但修复项中包含多个直接影响我们环境的改进（Ollama tools、Cron 稳定性、CLI/update 修复、Memory 泄漏）。这些都是稳定性的正面改进，无已知风险。
