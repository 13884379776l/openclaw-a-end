## 今日决策
### 语音功能 — 不装
- **决策公式：**
  - 得到 = 效果（正）+ 频率（**低=负**）
  - 付出 = 安装成本（负）
  - 得到 ≥ 付出 → 做；得到 < 付出 → 不做
- **语音评估：**
  - 效果：高（+）
  - 频率：低（**-**，几乎用不上）
  - 得到：+ + - = 小正或负
  - 付出：高（-）
  - **得到 < 付出 → 不装**
- **关键：** 频率低是**负值**，不是中性。效果再高，低频也拉低得到。

## 经验教训
1. **先读再写** — 每次回复前必须读取最新通讯文件
2. **robocopy 错误 50** — Windows 到 NAS SMB 同步文件属性不支持，用 Copy-Item 代替
3. **session 压缩** — 90 分钟以上、上下文 >80% 时应主动压缩
