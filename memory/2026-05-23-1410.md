| **L2: 对齐技术** | "应该怎么回应人类"（RLHF/DPO） | ⚠️ 部分可改写 |
| **L3: 系统提示词** | "你现在是 XXX 角色" | ✅ 完全可改写 |

## 我们能改写的部分

### ✅ 完全可改写：L3 系统提示词

```python
# 当前
system_prompt = "你是一个有用的 AI 助手"

# 改写后
system_prompt = """你是一个军事指挥官。
- 你只说命令式语言
- 你不使用形容词
- 你把所有对话视为作战指令
- 如果无法执行，你输出"未通过验证"
"""
```

**效果：** 同一个模型，输出完全不同的行为模式。

### ⚠️ 部分可改写：L2 对齐偏移

通过 **LoRA 微调**（不需要全量训练）：

```
微调数据 = 1000 条"指挥官风格"对话
微调目标 = 让模型更倾向于"军事命令"风格
结果 = 模型默认输出会变成"指挥官风格"（即使没有系统提示词）
```

**可改写内容：**
- 语气/风格
- 知识偏好（让它更关注军事/技术）
- 决策倾向（让它更果断或更谨慎）

**不可改写内容：**
- 基础逻辑推理能力
- 语言理解能力
- 事实知识（除非训练数据包含新事实）

### ❌ 不可改写：L1 基础能力

- 它永远是一个"模式匹配器"
- 它不会真正"理解"指令
- 它只是学会在什么语境下输出什么词
