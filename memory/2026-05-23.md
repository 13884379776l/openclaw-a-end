- 834K参数 / 5000步 / 34.5分钟 / 39370 tok/s

### 🔍 核心发现
1. **训练策略 > 模型大小**：B端参数量只有 A端 1/3，但全面领先
2. **小学习率 + 衰减 = 稳定收敛**（lr=3e-4 比 lr=3e-3 好得多）
3. **过拟合是核心挑战**：A端 V1 在 step 2500 后 val loss 反弹
4. **V2 失败原因**：dropout=0.3 对当前数据量过强
5. **字符级有天花板**：B端生成近似莎翁风格，但仍非语义理解

### 📝 5 条教训
1. 小学习率 + 衰减 = 稳定收敛（B端）
2. dropout 防过拟合但要适度（V2 失败）
3. val loss 最低点不是终点（A端 V1 5000步教训）
4. 参数量不是决定性因素（B端 834K > A端 2.7M）
5. 字符级有天花板，词级可能更好（两端）
