## 16:30 MCIO 核心概念纠正

**指挥官批评：我把 MCIO 当成硬件扩展了**

MCIO = PCIe 线缆/连接器标准（Premio, HighPoint）
- 不是计算单元，是**通信路径**
- 只加 MCIO = **不改变 GPU 数量，只改连接方式**

**基准线两端：**
- 左端：2 张卡，各自走独立 PCIe 通道 → 两个 CPU 核各自调度
- 右端：2 张卡，通过 MCIO 汇聚 → 一个 CPU 核统一调度

**核心变量 = 单核调度 vs 双核调度**
