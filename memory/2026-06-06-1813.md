### 🚨 深度诊断：为什么更换 CPU 后会导致网卡消失？

这通常不是软件配置问题，而是**硬件/驱动层面的故障**：

1. **驱动不匹配 (Kernel Driver Missing)**：
   新 CPU 可能改变了主板的 PCIe 总线拓扑，导致原有的内核驱动无法识别到网卡。或者您更换的是不同厂商的 CPU（例如 Intel $\leftrightarrow$ AMD），触发了某种硬件兼容性问题。
2. **BIOS 设置变更 (最可能的原因)**：
   更换 CPU 必然会导致 BIOS 重置。请检查您的 BIOS 设置中，**`Onboard LAN` 或 `Network Stack` 是否被禁用了 (`Disabled`)**。如果 BIOS 关了网卡，操作系统里就绝对看不到这个设备。
3. **硬件物理损坏/松动**：
   在操作 CPU 时，是否不小心碰到了主板上的其他组件？或者主板的 PCIe 通道因为 CPU 安装问题（如针脚接触不良）而导致部分外设（网卡）无法工作。
