## 🪟 Linux 设置

### 1. CPU 频率缩放
```bash
# 安装并设置 governor
sudo apt install cpufrequtils -y

# 查看当前模式
cpupower frequency-info

# 设置为 powersave（按需降频）
echo 'GOVERNOR=powersave' | sudo tee /etc/default/cpupower
sudo systemctl enable --now cpupower
```

### 2. USB/PCIe 自动暂停
```bash
# 创建 /etc/pm/power.d/auto-pause
echo -e '#!/bin/bash\necho min_power > /sys/bus/usb/devices/usb1/power/control\n' | sudo tee /etc/pm/power.d/auto-pause
sudo chmod +x /etc/pm/power.d/auto-pause

# 启用 PCIe ASPM（类似 Windows Deep Sleep）
echo "options iwlwifi power_save=1" | sudo tee /etc/modprobe.d/iwlwifi.conf
```

### 3. TLP（最推荐，一键省电）
```bash
sudo apt install tlp tlp-rdw -y
sudo tlp start

# 查看效果
tlp-stat -s   # 系统状态
tlp-stat -c   # CPU
tlp-stat -p   # PCIe ASPM
```

### 4. systemd sleep 设置
```bash
# /etc/systemd/logind.conf
HandleLidSwitch=ignore    # 笔记本才需要
IdleAction=hybrid-sleep   # 空闲后休眠

sudo systemctl restart systemd-logind
```

## 🛠️ BIOS 设置步骤

1. **开机狂按 `Del`** 进 BIOS
2. **按 `F7`** 切到 Advanced Mode
3. 菜单路径：**Settings** → **Advanced** → **Power Management Setup**

### 🔌 关键选项修改

| 选项 | 推荐设置 | 作用 |
|------|----------|------|
| **Deep Sleep** | **Enabled (ASPM)** | PCIe ASPM 节能，待机时降低功耗 |
| **ErP/EuP** | **Enabled (S4+S5)** | 关机后彻底切断 USB/主板供电（最低待机功耗） |
| **Restore on AC Power Loss** | **Power Off** | 停电恢复后不自动开机，防止误耗电 |

> ⚠️ **ErP Enabled 注意**：开启后关机状态下 USB、网口均断电。**无法通过 USB 键盘开机**或 **网络唤醒 (WoL)**。如果还需要这些功能，请关闭 ErP。

### ⚡ 其他节能点
- **Fast Boot**：`Settings` → `Advanced` → `Boot` → **Enabled**（跳过自检，缩短通电时间）
- **RGB Lighting**：`Settings` → `Motherboard` → `RGB LED Setting` → **Disable**（如果不需要灯光）

改完按 `F10` 保存重启。
