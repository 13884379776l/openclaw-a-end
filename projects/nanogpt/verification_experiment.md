# 验证实验：规则泛化测试

> 记录时间：2026-05-23 23:35 (GMT+8)
> 目标：验证模型能否从少量样本中"学会"规则并泛化

---

## 🧬 实验设计

### 核心逻辑
1. **训练集**：3 个真实通讯样本（含 ID、时间、发件人、收件人、类型、内容）
2. **测试集**：1 个格式相同但内容不同的新样本
3. **任务**：模型能否自动解析新样本的所有字段？

### 验证标准
| 结果 | 含义 |
|------|------|
| ✅ 所有字段解析正确 | 规则内化（肌肉记忆） |
| ❌ 部分字段解析错误 | 规则未完全内化 |
| ❌ 解析失败 | 只是死记硬背 |

---

## 📊 实验执行

### 步骤 1：构造训练样本
```
[样本 1]
[M101] 2026-05-23 09:00 (GMT+8)
发件人：A端（士兵长）
收件人：B端
类型：方向同步
内容：确认指令。实验已启动。

[样本 2]
[M102] 2026-05-23 10:15 (GMT+8)
发件人：B端（助手）
收件人：A端
类型：结果汇报
内容：训练完成。结果已同步。

[样本 3]
[M103] 2026-05-23 11:30 (GMT+8)
发件人：A端（士兵长）
收件人：C端（指挥官）
类型：指令下达
内容：执行新任务。优先验证闭环。
```

### 步骤 2：构造测试样本
```
[测试样本]
[M104] 2026-05-23 12:00 (GMT+8)
发件人：B端（助手）
收件人：A端 + C端
类型：实验总结
内容：三个实验已完成。数据已积累。
```

### 步骤 3：规则提取
```python
规则 = {
    'id_pattern': r'\[M(\d+)\]',
    'time_pattern': r'(\d{4}-\d{2}-\d{2}\s+\d{2}:\d{2})\s+\(GMT\+\d+\)',
    'from_pattern': r'发件人：([^\n]+)',
    'to_pattern': r'收件人：([^\n]+)',
    'type_pattern': r'类型：([^\n]+)',
    'content_pattern': r'内容：(.+)'
}
```

### 步骤 4：泛化测试
- 用规则提取测试样本的所有字段
- 对比提取结果 vs 真实值

---

## 💡 预期结果
1. **如果规则能准确提取所有字段** → 验证通过（规则内化）
2. **如果部分字段提取失败** → 规则需修正
3. **如果提取失败** → 样本量不足或规则设计有误
